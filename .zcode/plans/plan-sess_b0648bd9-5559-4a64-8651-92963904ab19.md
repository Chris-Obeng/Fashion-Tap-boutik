# Apple-monochrome rebuild of the Fashion Tap Boutik storefront

## Context
The app (Next 16.4.6 / React 19 / Tailwind v4 / HeroUI v3.2.7 / zustand) works end-to-end but is buried under "boutique editorial" clutter: promo marquee, ALL-CAPS tracked eyebrows everywhere, a 6-section homepage, a filter drawer for 20 products, non-functional wishlist/search, checkout summary rendered **three times**, and a 500 ms timer that auto-opens the cart. Half the components are 1,700–1,900-char single-line JSX files. Categories/empty-states/totals are copy-pasted in 4–6 places.

**Decisions (user-confirmed):** keep Fashion Tap Boutik + GH₵/Accra/Paystack context · ruthless minimal (remove marquee, editorial split, trust strips, wishlist, search overlay, filter drawer, announcement bar) · visual direction delegated → **Apple monochrome**.

## Design language (rewrite `app/globals.css` tokens + `app/layout.tsx`)
- **Palette:** bg `#fbfbfd`, ink `#1d1d1f`, secondary `#6e6e73`, faint `#86868b`, hairline `#d2d2d7`, soft surface `#f5f5f7` (Apple's gray), white surfaces. Clay `#a1512f` kept **only** for sale/compare-at prices. Focus ring `#0071e3` (Apple's a11y blue). Remap HeroUI v3 semantic tokens (`--surface*`, `--overlay*`, `--default*`, `--field-*`, `--separator`, `--backdrop`) to match.
- **Type:** drop Instrument Serif entirely (remove import in `app/layout.tsx`) — Geist only. Size-specific tracking per HIG: display −0.022em semibold, body 17px/1.47 tracking 0. **Kill every ALL-CAPS tracked eyebrow** — sentence case everywhere. Type scale: display clamp(40→56px) semibold, h2 40/48, nav 12px gray like apple.com.
- **Shape:** buttons `rounded-full` 44–48px tall; cards/images `rounded-[18px]`. Content width `max-w-[1200px]` (from 1480).
- **Motion (emil-design-eng + apple-design skills):** keep the custom easings already in globals (`--ease-out: cubic-bezier(0.23,1,0.32,1)` etc.); `active:scale(0.97)` 160ms ease-out on all pressables; UI transitions <300ms, ease-out on enter; sheets spring damping 1.0; hover effects gated `@media (hover:hover)`; keep `prefers-reduced-motion/-transparency/-contrast` blocks. Remove marquee keyframes, per-card stagger, link-underline draw (replace with simple opacity/color hover).

## Page-by-page

**Header** (`components/shared/header.tsx`, rewrite): remove announcement bar + search icon. Apple-style: 48px translucent bar (`rgba(251,251,253,.8)` + `blur(20px) saturate(180%)`), hairline bottom, Logo, nav (Shop all · Women · Men · Accessories · New in, 12px), bag button with count badge. Mobile: hamburger → clean full-height sheet, large type list.

**Footer** (`components/shared/footer.tsx`, rewrite): minimal — brand line, a few 12px gray links (TikTok, WhatsApp, Delivery & returns, Size guide), copyright. Remove payment chips row + floating WhatsApp button.

**Home** (`app/(storefront)/page.tsx`, rebuild ~120 lines): 4 sections only — (1) centered hero: "The everyday edit." + one gray subline + black pill "Shop now" + text link "New in ›", full-width hero image `rounded-[18px]`, no badges/coordinates/meta rows; (2) "Shop by category" — 4 equal tiles (no bento span map); (3) New arrivals rail; (4) Our favourites grid. Section-level fade-up only (simplified `Reveal`).

**Shop** (`app/(storefront)/shop/page.tsx` + `components/shop/shop-client.tsx`): category becomes the single source of truth — server filters by `await searchParams` (Next 16 promise API), pills are `<Link>`s, delete the `key={active}` remount + `router.replace` sync + duplicated filter predicate + filter drawer + Filters button + price slider. Client keeps sort only (Featured / Newest / Price). Count line + clean 2/3/4-col grid + empty state. Restyle `loading.tsx`.

**Product** (`components/product/product-info.tsx` rewrite, `product-gallery.tsx` restyle, page restyle): sticky info column — small gray category line, name, price (+clay struck compare-at), description; color swatches with **luminance-derived check contrast** (replace hardcoded name check); size pills; quantity + Add to bag; feedback = brief check morph + toast with "View bag" action (deletes the 500ms auto-open timer, `added` gate, reduced-motion branch). Keep 3-item accordion (Details / Size guide / Delivery & returns), delete 3-icon trust row. Keep mobile sticky add-to-bag bar (restyled). Related section uses shared rail.

**Cart** (`components/cart/cart-panel.tsx` rewrite, formatted): keep bottom-sheet/right-drawer pattern (`responsive-panel.tsx` stays); white surface, hairlines, black pill "Check out". Shared `EmptyBag` component (also used by checkout).

**Checkout** (`components/checkout/checkout-form.tsx` rewrite, formatted): **one** summary card (compact thumbnail rows + shared `OrderTotals`) above the form — kills the triplication (desktop aside + mobile `<details>` + fixed pay bar all deleted). Single column `max-w-[720px]`. Plain h2 group headings (no 01/02). Delivery vs pickup as quiet selectable rows (HeroUI RadioGroup restyled). One black pill "Pay GH₵ X" at the end. Keep RHF + zod schema, area fees, mock payment, sessionStorage handoff (simplify sentinel parsing). Extract `ChromeHeader` shared by checkout layout + order page (dedupes the inline 76px headers).

**Order success** (`components/checkout/order-success.tsx` restyle): centered check, "Thank you", ref, items + shared totals, delivery card, "Continue shopping".

**New:** `app/not-found.tsx` (clean 404) and `app/error.tsx` (minimal reset fallback).

## Dedupe / dead-code removal
- Single source for nav/category lists in `data/categories.ts` (header, footer, shop pills all import it); delete unused `editorial.portrait` + `story` if the new home doesn't use them.
- New shared: `product-rail.tsx`, `empty-bag.tsx`, `order-totals.tsx`, `chrome-header.tsx`.
- Delete: `search-overlay.tsx`, `trust-strip.tsx`, wishlist state in `product-card.tsx`, `lib/products.ts#searchProducts`, `.rule`/`.snap-row`/marquee CSS, bogus `cn-toast` class, unused `SelectContent align` prop.
- Keep unchanged: `store/cart.ts` (zustand + skipHydration pattern), `lib/` seams (payments mock, checkout-schema, format, config, button-class), `components/ui/*` wrappers (minor trims).
- **Bug fix:** product image URLs use `q=85` but Next 16 defaults `images.qualities` to `[75]` — set `qualities: [75, 85]` in `next.config.ts` (or normalize URLs to 75).
- All rewritten files get properly formatted multi-line JSX (no 1,900-char lines).
